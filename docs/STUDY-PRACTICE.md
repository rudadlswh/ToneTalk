# Study 연습 모드

기존 간격 반복 복습은 Study 홈 하단의 **저장 표현 복습**에서 그대로 사용할 수 있다.

## MVP 범위

- 어투 퀴즈: 기존 5개 어투 중 정답을 포함한 4지선다, 즉각 해설, 첫 선택 정답 시 20 XP.
- 단어 나열 퍼즐: 단어 선택/제거/초기화/채점/정답 보기. 정답 공개 없이 완성 시 25 XP.
- 퀴즈·퍼즐은 영어 기본 예문 5개 또는 최신 저장 문장 최대 100개에서 5문제를 선정한다. 퍼즐은 Intl.Segmenter로 일본어·중국어도 분리하며 2~24개 블록 문장만 사용한다. 복수 정답을 추론하지 않고 저장된 문장의 순서를 기준으로 채점한다.
- 롤플레이: 카페/회의/친구, 기존 7개 언어, 사용자 4회 발화 후 완료 35 XP. 답변과 한국어 어투 코칭 및 추천 표현을 제공한다. 실제 원어민이 아닌 AI 파트너이며 피드백 정확성은 보장하지 않는다.
- XP는 Study 컴포넌트가 유지되는 동안만 합산한다. 퀴즈·퍼즐은 동일 문제 중복 지급을 막는다. 계정 XP, 서버 저장, 기존 복습 통계 연동은 포함하지 않는다.
- 채팅 기록은 컴포넌트 메모리에만 보관하며 모드 변경/페이지 이탈 시 초기화한다. 서버는 전달된 문맥을 AI 입력으로만 사용하고 DB에 저장하지 않는다. 공급자/터널 자체 로깅 정책은 별개다.

## API

`POST /api/study/chat`: `{ scenario: "cafe" | "meeting" | "friends", language, messages: [{ role: "user" | "assistant", content }] }`

응답: `{ reply, feedback, suggestion, requestId }`. 입력은 교대 순서, 마지막 user, 최대 7개 메시지와 메시지당 1,200자를 검증한다. 본문은 최대 24KB. Ollama 출력은 필수 문자열 필드를 검증한다.

기존 OLLAMA_BASE_URL/MODEL/TIMEOUT 및 Basic Auth를 그대로 사용한다. 단일 요청/최대 500 출력 토큰, 자동 재시도 없음. 취소 신호와 타임아웃을 전달한다. CPU 환경에서 즉시 응답을 약속하지 않는다.

같은 출처 검사와 인스턴스 메모리 기반 IP당 분당 6회 제한을 적용한다. 이는 인증이나 전역 제한을 대체하지 않는다. 현재 앱의 단일 사용자 공개 접근 모델을 유지하므로 대규모 공개 전에는 이메일 인증, 소유권 확인 및 전역 사용량 제한이 필요하다.

## 검증

`pnpm test:run`, `pnpm lint`, `pnpm build`.

브라우저 확인: 기본 퀴즈 정답/오답/종료, 퍼즐 중복 단어/초기화/정답 공개, 빈 저장 목록과 API 실패, 채팅 성공/실패/취소/새 대화, 4회 완료 및 화면 이탈 시 취소, 390px 모바일 화면.

새 DB 테이블/마이그레이션/패키지/환경변수는 없다. 실제 Ollama 품질과 응답 시간은 운영 모델로 별도 측정해야 한다.
